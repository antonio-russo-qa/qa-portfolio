SITO ANTONIO RUSSO - PUBBLICAZIONE SU GITHUB PAGES
==================================================

Contenuto della cartella
  index.html    il sito (una sola pagina con Home, About, Metodo, Progetti, Contatti)
  images/       le foto usate dal sito
  deploy.ps1    lo script che pubblica tutto su GitHub

Prima volta: cosa serve
  - Git per Windows: https://git-scm.com/download/win
  - Un account GitHub con accesso al repository antonio-russo-qa/qa-portfolio

Pubblicare
  1. Estrai lo zip.
  2. Nella cartella estratta: Shift + tasto destro > "Apri finestra PowerShell qui".
  3. Lancia:
       powershell -ExecutionPolicy Bypass -File .\deploy.ps1
  4. Controlla l'elenco dei file e rispondi "s" per pubblicare.
     Al primo invio GitHub potrebbe aprire una finestra di login nel browser.
  5. Dopo 1-2 minuti il sito e online: https://antonio-russo-qa.github.io/qa-portfolio/
     (se vedi la versione vecchia: Ctrl + F5)

Note
  - Le vecchie pagine (chi-sono.html, competenze.html, ecc.) restano nel repository ma
    non sono piu collegate dal nuovo sito. Puoi cancellarle quando vuoi.
  - Per aggiornare il sito in futuro basta sostituire index.html e rilanciare lo script.
