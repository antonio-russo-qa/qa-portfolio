Progetti

Una selezione delle principali esperienze maturate come QA Engineer in differenti contesti tecnologici: dall'automazione software alle piattaforme IoT, dalla realtà virtuale alla cybersecurity, fino agli ambienti enterprise ad alta complessità.

SPORTS ANALYTICS · TEST AUTOMATION

Sports Analytics & QA Automation

Attività di Quality Assurance su una piattaforma digitale dedicata alla gestione e all'analisi di dati e performance sportive.

Ho svolto attività di Quality Assurance su una piattaforma digitale caratterizzata da diversi livelli applicativi, occupandomi della validazione delle funzionalità, dei servizi backend e della qualità dei dati.

Le attività hanno compreso Functional Testing, Regression Testing e REST API Testing attraverso Swagger e Postman, oltre alla progettazione dei test case e alla gestione strutturata dei difetti tramite Jira.

Una parte significativa dell'attività è stata dedicata alla Test Automation dei principali flussi end-to-end attraverso Selenium WebDriver, con l'obiettivo di rendere le verifiche più rapide, ripetibili e affidabili.

Ho inoltre lavorato sulla validazione dei dati attraverso SQL e PL/SQL, sui test di integrazione tra i diversi livelli applicativi, sull'accessibilità secondo gli standard WCAG e sull'analisi UX/UI tramite Axe DevTools.

Selenium WebDriver REST API Swagger Postman SQL / PL-SQL Jira WCAG Axe DevTools

MEDICAL IoT · MOBILE · INTEGRATION

Medical IoT & Mobile Testing

Attività di Quality Assurance su una piattaforma Medical IoT orientata al monitoraggio remoto attraverso dispositivi connessi.

L'attività di QA ha richiesto una visione trasversale del sistema, verificando la corretta comunicazione tra dispositivi, applicazioni mobile, servizi backend e infrastruttura cloud.

Ho svolto attività di Functional e Integration Testing, verificando i flussi applicativi e l'integrazione tra i diversi componenti della piattaforma.

La validazione delle REST API è stata affiancata da attività di Test Automation mediante Selenium WebDriver.

Una componente particolarmente importante è stata rappresentata dal testing della comunicazione BLE (Bluetooth Low Energy) e dalla verifica dell'integrazione device → cloud → mobile.

L'attività ha inoltre richiesto Mobile Testing su piattaforme iOS e Android, utilizzando TestFlight e APK, oltre alla verifica dell'accessibilità secondo WCAG 2.1 e all'analisi dell'usabilità delle interfacce.

Medical IoT BLE REST API Selenium WebDriver iOS Android TestFlight WCAG 2.1

VR · WEBGL · PERFORMANCE

VR & WebGL Quality Assurance

Attività di Quality Assurance su una piattaforma immersiva basata su realtà virtuale e tecnologie WebGL.

L'attività ha combinato Quality Assurance, Realtà Virtuale, WebGL e contenuti digitali immersivi, richiedendo un approccio di testing differente rispetto alle applicazioni web tradizionali.

Le attività di testing hanno riguardato i principali flussi funzionali della piattaforma, con Functional, Integration e Regression Testing all'interno di un ambiente Agile.

Ho inoltre effettuato la validazione delle REST API attraverso Swagger e Postman, verificando richieste, risposte e comportamento dei servizi.

Una particolare attenzione è stata dedicata alla componente immersiva, verificando performance, rendering e stabilità degli ambienti VR/WebGL.

L'attività ha incluso inoltre Accessibility Testing mediante Axe DevTools e verifiche rispetto agli standard WCAG, oltre a Mobile Testing su dispositivi iOS e Android e gestione tecnica delle anomalie.

VR WebGL Swagger Postman REST API WCAG Axe DevTools Mobile Testing

IoT · CYBERSECURITY · EMBEDDED

IoT Security & Embedded Testing

Attività di Quality Assurance su sistemi embedded e dispositivi IoT con particolare attenzione alla sicurezza e alla stabilità delle comunicazioni.

Ho lavorato su sistemi embedded e dispositivi IoT caratterizzati da una significativa componente di Cybersecurity. L'attività di QA ha richiesto la validazione sia dei comportamenti funzionali sia della sicurezza e della stabilità delle comunicazioni.

Ho eseguito attività di Functional, Integration e Regression Testing, verificando la corretta comunicazione attraverso protocolli e interfacce come MQTT, Zigbee e API.

Una componente centrale è stata rappresentata dal Security Testing, utilizzando strumenti come Burp Suite e OWASP ZAP per analizzare il comportamento dei sistemi e individuare potenziali vulnerabilità.

Ho inoltre eseguito attività di Performance Testing con Apache JMeter, troubleshooting e supporto agli ambienti di staging, collaborando con i team tecnici durante le fasi di analisi e risoluzione delle anomalie.

IoT Embedded MQTT Zigbee API Testing Burp Suite OWASP ZAP JMeter

ENTERPRISE · BACKEND · MIGRATION

Enterprise Backend Migration Testing

Attività di Quality Assurance nell'ambito di una complessa migrazione backend in ambiente enterprise.

Ho lavorato sul testing di una migrazione backend all'interno di un ambiente enterprise caratterizzato da numerose integrazioni tra servizi, API, database e componenti middleware.

Le attività hanno incluso Functional e Integration Testing, con particolare attenzione alla corretta comunicazione tra i diversi sistemi coinvolti nella migrazione e alla conservazione del comportamento funzionale dell'applicazione.

Ho effettuato la validazione delle REST API e delle comunicazioni middleware, oltre alla progettazione di Test Plan e Test Case dedicati alle verifiche post-migrazione.

La gestione del ciclo di vita dei difetti è stata condotta attraverso strumenti di Defect Management, con collaborazione costante con i team di sviluppo e infrastruttura per l'analisi delle anomalie, la loro riproduzione e la verifica delle correzioni.

Backend Testing Migration Testing REST API Integration Testing Middleware Test Case Design Defect Management Enterprise QA

ENTERPRISE · CROSS-MODULE · API TESTING

Enterprise Cross-Module QA

Attività di Quality Assurance cross-module su una piattaforma enterprise ad alta complessità.

Questa esperienza rappresenta un'attività significativa nel testing di una piattaforma enterprise caratterizzata da numerosi moduli applicativi e da una forte interazione tra sistemi differenti.

Il lavoro comprende Functional, Integration, System e Regression Testing, con l'obiettivo di garantire la stabilità delle funzionalità durante i diversi cicli di release e ridurre il rischio di regressioni.

Una parte importante dell'attività riguarda la validazione delle REST API tramite Postman e la verifica dei dati attraverso SQL su database enterprise, consentendo controlli sia a livello applicativo sia direttamente sul layer dati.

Il processo di Quality Assurance comprende inoltre la gestione del Defect Lifecycle, la validazione UX/UI e la collaborazione con team multidisciplinari all'interno di ambienti Agile/Scrum.

L'approccio cross-module consente di analizzare l'impatto delle modifiche sull'intero ecosistema, contribuendo alla qualità delle release e alla riduzione dei difetti post-release.

Functional Testing Integration Testing Regression Testing System Testing Postman REST API SQL Defect Lifecycle UX/UI Testing Agile / Scrum
