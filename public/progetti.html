SPORTS ANALYTICS PLATFORM

SPORTS ANALYTICS & QA AUTOMATION

Piattaforma digitale dedicata alla gestione e all'analisi delle performance nel settore sportivo.

Ho lavorato su attività di Quality Assurance all'interno di una piattaforma digitale orientata alla gestione e all'analisi delle performance sportive. Il lavoro ha coinvolto diversi livelli dell'applicazione, dalla validazione funzionale delle interfacce fino ai servizi backend e alla qualità dei dati.

Le attività hanno compreso Functional Testing, Regression Testing e REST API Testing attraverso Swagger e Postman, oltre alla progettazione di test case e alla gestione strutturata dei difetti.

Una parte significativa del progetto è stata dedicata all'automazione dei principali flussi end-to-end tramite Selenium WebDriver, permettendo di validare in modo ripetibile i percorsi funzionali più critici dell'applicazione.

Ho inoltre lavorato sulla validazione dei dati attraverso SQL e PL/SQL, sui test di integrazione tra i diversi livelli applicativi, sull'accessibilità secondo gli standard WCAG e sull'analisi UX/UI mediante Axe DevTools.

Selenium WebDriver REST API Swagger Postman SQL / PL-SQL Jira WCAG Axe DevTools

MEDICAL IoT & REMOTE REHABILITATION

MEDICAL IoT & MOBILE TESTING

Piattaforma Medical IoT per il monitoraggio e la riabilitazione remota attraverso dispositivi connessi.

Il progetto ha riguardato una piattaforma IoT orientata al settore medicale e alla riabilitazione da remoto. L'attività di QA ha richiesto una visione trasversale del sistema, verificando la corretta comunicazione tra dispositivi, applicazione mobile, servizi backend e infrastruttura cloud.

Ho svolto attività di Functional e Integration Testing, verificando i flussi applicativi e l'integrazione tra i diversi componenti della piattaforma. La validazione delle API REST è stata affiancata da attività di test automation mediante Selenium WebDriver.

Una componente particolarmente importante è stata rappresentata dal testing della comunicazione BLE (Bluetooth Low Energy) e dalla verifica dell'integrazione device → cloud → mobile.

Il progetto ha inoltre richiesto attività di mobile testing su piattaforme iOS e Android, utilizzando TestFlight e APK, oltre alla verifica dell'accessibilità secondo WCAG 2.1 e all'analisi dell'usabilità delle interfacce.

Medical IoT BLE REST API Selenium WebDriver iOS Android TestFlight WCAG 2.1

VR & CULTURAL HERITAGE

VR & WEBGL QUALITY ASSURANCE

Piattaforma di realtà virtuale dedicata alla valorizzazione del patrimonio culturale.

Ho lavorato su un progetto caratterizzato da una forte componente tecnologica, combinando Quality Assurance, Realtà Virtuale, WebGL e Cultural Heritage.

Le attività di testing hanno riguardato i principali flussi funzionali della piattaforma, con Functional, Integration e Regression Testing all'interno di un ambiente Agile. Ho inoltre effettuato la validazione delle REST API attraverso Swagger e Postman.

Una particolare attenzione è stata dedicata alla componente immersiva, verificando performance, rendering e stabilità degli ambienti VR/WebGL. Questo ha richiesto un approccio di testing differente rispetto alle applicazioni web tradizionali.

Il progetto ha incluso inoltre attività di Accessibility Testing mediante Axe DevTools e verifiche rispetto agli standard WCAG, oltre a mobile testing su dispositivi iOS e Android e gestione dei bug attraverso attività di reporting tecnico.

VR WebGL Swagger Postman REST API WCAG Axe DevTools Mobile Testing

IoT · CYBERSECURITY · EMBEDDED

IoT SECURITY & EMBEDDED TESTING

Progetto IoT orientato alla sicurezza di sistemi embedded e alla comunicazione tra dispositivi.

Ho lavorato su sistemi embedded e dispositivi IoT caratterizzati da una forte componente di cybersecurity. L'attività di QA ha richiesto la validazione non soltanto dei comportamenti funzionali, ma anche della sicurezza e della stabilità delle comunicazioni.

Ho eseguito attività di Functional, Integration e Regression Testing, verificando la corretta comunicazione attraverso protocolli e interfacce come MQTT, Zigbee e API.

Una componente centrale è stata rappresentata dal Security Testing, utilizzando strumenti come Burp Suite e OWASP ZAP per analizzare il comportamento dei sistemi e individuare potenziali vulnerabilità.

Ho inoltre eseguito attività di Performance Testing con Apache JMeter, troubleshooting e supporto agli ambienti di staging, collaborando con i team tecnici durante le fasi di analisi e risoluzione delle anomalie.

IoT Embedded MQTT Zigbee API Testing Burp Suite OWASP ZAP JMeter

ENTERPRISE · BACKEND MIGRATION

ENTERPRISE BACKEND MIGRATION TESTING

Attività di Quality Assurance nell'ambito di una complessa migrazione backend in ambiente enterprise.

Il progetto ha riguardato il testing di una migrazione backend all'interno di un ambiente enterprise caratterizzato da numerose integrazioni tra servizi, API, database e componenti middleware.

Le attività hanno incluso Functional e Integration Testing, con particolare attenzione alla corretta comunicazione tra i diversi sistemi coinvolti nella migrazione e alla conservazione del comportamento funzionale dell'applicazione.

Ho effettuato la validazione delle REST API e delle comunicazioni middleware, oltre alla progettazione di Test Plan e Test Case dedicati alle verifiche post-migrazione.

La gestione del ciclo di vita dei difetti è stata condotta attraverso strumenti di defect management, con collaborazione costante con i team di sviluppo e infrastruttura per l'analisi delle anomalie, la loro riproduzione e la verifica delle correzioni.

Backend Testing Migration Testing REST API Integration Testing Middleware Test Case Design Defect Management Enterprise QA

ENTERPRISE · CROSS-MODULE QA · DIGITAL PLATFORM

ENTERPRISE CROSS-MODULE QA

Attività di Quality Assurance cross-module su una piattaforma enterprise ad alta complessità.

Il progetto rappresenta un'esperienza significativa nel testing di una piattaforma enterprise caratterizzata da numerosi moduli applicativi e da una forte interdipendenza tra i diversi componenti del sistema.

Il lavoro comprende Functional, Integration, System e Regression Testing, con l'obiettivo di garantire la stabilità delle funzionalità durante i diversi cicli di release e ridurre il rischio di regressioni in produzione.

Una parte importante dell'attività riguarda la validazione delle REST API tramite Postman e la verifica dei dati attraverso SQL su database enterprise, consentendo di effettuare controlli sia a livello applicativo sia direttamente sul layer dati.

Il processo di Quality Assurance comprende inoltre la gestione del defect lifecycle, la tracciabilità dei requisiti e dei test, la validazione UX/UI e la collaborazione con team multidisciplinari all'interno di ambienti Agile/Scrum.

L'approccio cross-module consente di analizzare l'impatto delle modifiche sull'intero ecosistema, contribuendo alla qualità delle release e alla riduzione dei difetti post-release.

Functional Testing Integration Testing System Testing Regression Testing Postman REST API Oracle SQL Defect Management UX/UI Testing Agile / Scrum
